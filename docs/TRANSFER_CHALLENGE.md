# Interview modes

Standard mode asks independent questions about the submitted work. Each answer is assessed separately.

Challenging mode selects two or three concepts. The student explains each idea, then applies it to a small change. If the first answer is wrong, missing or “I do not know”, the application question for that concept is skipped.

The report shows the explanation and application together. It scores the explanation, application and consistency from 0 to 2, with supporting answer quotes. A skipped application is shown as skipped.

The three demo assignments use prepared question sets. New live assignments use the submitted work and the teacher’s chosen concepts. Practice mode uses sample logic, so it does not validate real AI accuracy.

Tests cover question order, skipped follow-ups, grading and saved reports. Run `npm test` and `npm run test:ui` to check them.
